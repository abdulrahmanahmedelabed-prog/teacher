# 🤖 خادم «المعلم الذكي»

خادم صغير (Cloudflare Worker) يربط تطبيق «رحلة العودة» بـ Claude، **ويحمي مفتاح الـ API** فلا يوضع داخل التطبيق.

## 💰 التكلفة بصراحة
- **لا يوجد Claude API مجاني.** لكن النموذج الافتراضي **Claude Haiku 5.5** رخيص جداً:
  0.10$ لكل مليون كلمة-رمز (token) داخلة و0.50$ للخارجة.
- الكتاب يُرفع **مرة واحدة** ويُخزَّن مؤقتاً، فالأسئلة التالية عليه أرخص بكثير.
- تقدير تقريبي: فصل من 30 صفحة ≈ 25–40 ألف رمز ⇐ أول سؤال ≈ سنت واحد تقريباً، والأسئلة التالية أقل.
- «شرح أعمق» يستخدم **Claude Sonnet 5.5** (2$ / 10$ للمليون) — أغلى بـ 20 ضعفاً، لذلك هو اختياري.
- Cloudflare Workers مجاني حتى 100,000 طلب يومياً.
- الحماية من الإسراف: حد يومي لكل جهاز (40 سؤالاً و10 رفعات افتراضياً)، ويمكنك وضع **حد إنفاق شهري** من لوحة Claude Console.

## 🚀 التشغيل (مرة واحدة، حوالي 10 دقائق)
1. أنشئ حساباً في <https://console.anthropic.com>، أضف رصيداً صغيراً (5$ تكفي لآلاف الأسئلة)، وضع **حد إنفاق شهري**، ثم أنشئ مفتاح API.
2. أنشئ حساباً مجانياً في <https://dash.cloudflare.com>.
3. على جهازك (يحتاج Node.js):
```bash
cd ai-proxy
npm install
npx wrangler login
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler deploy
```
4. سيظهر رابط مثل `https://rehla-ai.<اسمك>.workers.dev` — ضعه في `www/data.js`:
```js
const AI_CONFIG = { proxyUrl: "https://rehla-ai.<اسمك>.workers.dev" };
```
5. (مُوصى به) فعّل الحد اليومي لكل جهاز:
```bash
npx wrangler kv namespace create LIMITS
```
ثم انسخ الرقم إلى `wrangler.toml` (قسم `kv_namespaces`) وأعد `npx wrangler deploy`.

## 🔒 الخصوصية والأمان
- المفتاح يبقى في Cloudflare كـ secret، ولا يصل للتطبيق أبداً.
- يقبل الخادم الطلبات فقط من موقع التطبيق وتطبيق Android (`ALLOWED_ORIGINS`).
- الكتب المرفوعة تُحذف تلقائياً بعد 90 يوماً.
- النماذج: Haiku 5.5 بجهد منخفض (`effort: low`) للسرعة والتوفير، وSonnet 5.5 عند طلب «شرح أعمق» مع بديل تلقائي عند الرفض.
