# رحلة العودة — نسخة Flutter (Android)

نسخة أصلية (Native) مكتوبة بـ Flutter من تطبيق **«رحلة العودة»**: تطبيق مجاني يعمل بدون إنترنت،
بالعربية ومن اليمين لليسار، لطلاب المدارس والجامعات العائدين إلى الدراسة بعد انقطاع طويل
(كثيراً بسبب الحرب أو النزوح). يبدأ بخطوات صغيرة جداً ثم يزيد الحِمل تدريجياً.

- معرّف التطبيق: `com.rehla.flutter` — الاسم على الهاتف: «رحلة العودة».
- أقل إصدار Android: 6.0 (API 23). إذن الإشعارات في Android 13+ يُطلب فقط من بطاقة التذكير اللطيفة.

## العلاقة بتطبيق الويب

تطبيق الويب في `www/` (JavaScript بدون مكتبات) هو **المرجع**. هذه النسخة تنقل نفس المنطق حرفياً:

| الويب (`www/app.js`) | Flutter (`lib/logic/`) |
| --- | --- |
| `stats()` السلسلة المتسامحة مع 🧊 أيام السماح، العودة بعد انقطاع، الحِمل الثقيل | `stats.dart` |
| `levelInfo()` — XP(L) = 50·L·(L−1) | `levels.dart` |
| `buildDaily()` بذرة FNV-1a ‏(التاريخ + مرات التغيير + الاسم) ثم mulberry32، و`subjectPlan()` | `rng.dart`، `daily.dart` |
| تمييز العدد `arDays` / `arMins` / `arCount`، وصيغة المؤنث `gtext()` | `arabic.dart` |
| لايتنر `BOX_DAYS = [0,1,2,4,8,16,30]` | `leitner.dart` |
| `planNotifications()`: تذكير يومي، «اشتقنا لك» بعد 2، 4، 7، 14، 30 يوماً ثم نتوقف، لا إشعارات 21:30–07:00، الجمعة مطفأة افتراضياً، الهاتف المشترك | `reminders.dart` |
| البيانات الثابتة `www/data.js` | `lib/data/content.dart` (مولَّد منها) |

**التطابق مُختبَر آلياً:** السكربت `tool/gen_web_golden.js` يشغّل دوال الويب نفسها (من `www/app.js`)
ويحفظ نتائجها في `test/fixtures/web_golden.json`، ثم `test/web_parity_test.dart` يتأكد أن Dart
يعطي **نفس التحديات اليومية حرفاً بحرف** ونفس الإحصاءات ونفس خطة الإشعارات.

لإعادة توليد القيم المرجعية بعد تعديل منطق الويب:

```bash
cd flutter_app
TZ=Asia/Gaza node tool/gen_web_golden.js > test/fixtures/web_golden.json
flutter test
```

**النسخة الاحتياطية متوافقة:** الحالة كلها كائن JSON واحد بنفس أسماء الحقول (`profile`, `xp`, `history`,
`daily`, `cards`, `assess`, `badges`, `journal`, `settings`, `reminders`, `best`…)، فملف
«تصدير» من الويب يُستورد هنا والعكس، مع تنظيف البيانات المستوردة كما يفعل `sanitizeState`.

## ما الموجود

- البداية: سؤال واحد في كل شاشة مع نقاط التقدّم (الاسم ← المرحلة ← الصف ← المواد ← الوقت والموعد ← مدة الغياب ← تقييم كل مادة بخمسة وجوه)، ثم نافذة الخطة.
- الرئيسية: البطاقة الترحيبية (المستوى، اللقب، المرحلة، التقدّم)، المزاج (6 حالات، يوم راحة، ملاحظة عناية بعد 3 أيام صعبة)، «👉 خطوتك التالية»، زر «🧭 تايه؟» (5 خطوات)، بطاقة التقدّم المطوية (الأسبوع، السلسلة 🧊، دقائق التركيز، الأوسمة، تحدي الأسبوع)، والاقتباس.
- التحديات: قائمة اليوم، التبديل مع النقاط، التغيير مرة يومياً، التأمّل اليومي (+15 ⭐).
- مؤقت التركيز: وضع ملء الشاشة مع الحلقة، وقت انتهاء مطلق محفوظ، إنهاء مبكر يحسب 3 دقائق فأكثر، إنجاز التحدي المرتبط تلقائياً ونافذة «التالي»، وإشعار عند الانتهاء.
- البطاقات (لايتنر): إضافة وحذف، مراجعة بالقلب، ✔ عرفتها / ✖ ما عرفتها، شريط الإتقان، مواعيد نسبية.
- الألعاب: سباق الأرقام (60 ثانية)، تحدي المعلومات (10 أسئلة حسب الصف والمواد، وإضافة الخطأ للبطاقات)، الذاكرة (8 أزواج). حد 60 ⭐ يومياً.
- رحلتي: المراحل الخمس، مستوى المواد وإعادة التقييم، الأوسمة الـ18، اليوميات، ومشاركة الإنجاز كصورة.
- الإعدادات: الملف الشخصي وصيغة المخاطبة، المظهر (تلقائي/فاتح/داكن)، التذكيرات كاملة، الصوت والاهتزاز والساعات الهادئة، النسخ الاحتياطي، المنطقة الخطرة، الرأي (بريد إلى meheba65@gmail.com) والتواصل مع هبة أبو اللبن.
- الأصوات: نفس وصفات `www/sound.js` (سلّم «ري» الخماسي) تُولَّد كملفات WAV في الذاكرة عند التشغيل — بلا ملفات صوت مرفقة.
- كتبي: إضافة PDF أو صورة (تُحفظ على الجهاز) أو رابط، وقراءتها. **المعلم الذكي (Gemini) غير منقول بعد لهذه النسخة**: في تطبيق الويب وتطبيق Capacitor يعمل عبر Firebase AI Logic مع App Check (reCAPTCHA). نقله إلى Flutter يحتاج App Check بـ Play Integrity، وهذا يتطلب نشر التطبيق على Google Play (رسوم حساب مطوّر)، لذلك أبقيناه مطفأ للحفاظ على مبدأ «بلا أي تكلفة».

## البنية

```
lib/
  main.dart, app.dart        التشغيل، اللغة العربية، الثيم
  data/                      المحتوى الثابت (منقول من data.js) ونصوص الواجهة
  models/                    الحالة (AppData) بنفس حقول الويب + التنظيف
  logic/                     منطق Dart خالص قابل للاختبار
  state/                     AppState (ChangeNotifier) والأحداث للواجهة
  services/                  التخزين، الإشعارات، الصوت، المشاركة، المعلم الذكي
  theme/                     ألوان styles.css (فاتح وداكن)
  ui/screens, ui/widgets     الشاشات والعناصر
test/                        اختبارات المنطق والتطابق مع الويب واختبار دخان للواجهة
tool/gen_web_golden.js       توليد القيم المرجعية من منطق الويب
```

## البناء

يحتاج Flutter (القناة stable) وJava 17 وAndroid SDK:

```bash
cd flutter_app
flutter pub get
flutter analyze
flutter test
flutter build apk --release   # موقّع بمفتاح التصحيح ليُثبَّت مباشرة
```

البناء الآلي: `.github/workflows/flutter.yml` يبني عند كل دفع إلى `main` أو `claude/**`،
ويرفع الملف `rehla-flutter.apk` كـ artifact وفي صفحة الإصدارات بالوسم `flutter-latest`.

للنشر في Google Play: أضف مفتاح توقيع خاصاً في `android/app/build.gradle.kts` بدل مفتاح التصحيح.

## ما لم يُنقل بعد

- الواجهة المبسّطة للصغار (الصف 1–3)، والقراءة بصوت، والإملاء الصوتي، والتسجيل الصوتي، وألعاب «كم عددها؟» و«اسمع واختر» وبطاقات الحروف (أُضيفت حديثاً لنسخة الويب). إعداداتها تُحفظ كما هي عند الاستيراد.
- زر «ذكّرني بعد ساعة» في الإشعار (موجود فقط «ابدأ 5 دقائق»)، وتصدير التذكير كملف تقويم ‎.ics.
- تصغير صور الصفحات قبل حفظها، وعرض تنسيق Markdown في ردود المعلم (يُعرض نصاً عادياً).
- iOS (المشروع لـ Android فقط حالياً).

## فروق مقصودة عن الويب

- تحديات اليوم وحالة إنجازها تُحفظ عند إغلاق التطبيق وفتحه في نفس اليوم (الويب يعيد توليدها عند كل تحميل؛ النتيجة نفسها لأن التوليد حتمي، لكن الإنجاز يبقى هنا).
- الإشعارات تُجدول بالوقت المطلق (UTC) فلا حاجة لمعرفة المنطقة الزمنية للجهاز.
- الخلفية الهادئة (ضجيج بنّي) والضغط الصوتي تقريب بسيط لما يفعله Web Audio.
