# 🚀 رحلة العودة

تطبيق تحفيزي للطلاب الذين ابتعدوا عن الدراسة فترة، ولم يعودوا يعرفون من أين يبدؤون.
يعيد الطالب للدراسة **خطوة بخطوة** عبر تحديات يومية ونقاط ومستويات وأوسمة، ويجعل الرحلة ممتعة.

## ✨ الميزات

| الميزة | الوصف |
|---|---|
| 🗺️ **رحلة العودة (5 مراحل)** | إشعال الشرارة ← بناء العادة ← استعادة الأساس ← الانطلاق ← التفوّق. تبدأ الجلسات بربع وقتك اليومي وتزيد تدريجياً مع كل يوم دراسة. |
| 🎯 **تحديات يومية ذكية** | تُولَّد كل يوم حسب موادك ومرحلتك ومزاجك: إحماء، دراسة، استرجاع، إبداع، عناية بالنفس. |
| 🧭 **زر «تايه؟ من وين أبدأ»** | 5 خطوات صغيرة جداً تكسر حاجز البداية. |
| 😊 **سؤال المزاج** | إذا كان يومك صعباً تخفّ التحديات تلقائياً، وإذا كنت متحمساً يظهر تحدٍّ إضافي. |
| ⏱️ **مؤقت تركيز (بومودورو)** | كل دقيقة تركيز = 2 نقطة. يكمل حتى لو أُغلق التطبيق أو انقطعت الكهرباء. |
| 🧠 **ألعاب ذهنية** | سباق الأرقام (يصعب مع مستواك) ولعبة الذاكرة. |
| ⭐ **نقاط ومستويات وأوسمة** | 10 ألقاب و14 وساماً، وسلسلة أيام متتالية 🔥، وتحدي أسبوعي بمكافأة كبيرة. |
| 📓 **تأمّل يومي** | سجلّ لما تعلمته يومياً. |
| 💾 **يعمل بدون إنترنت** | كل البيانات على جهازك، ويمكنك نسخها احتياطياً ونقلها. |

## 📱 النسختان

### 1) نسخة الويب (PWA) — تعمل على أي موبايل
- تُنشر تلقائياً على **GitHub Pages** عبر `.github/workflows/pages.yml`.
- افتح الرابط من الموبايل ثم اختر **«إضافة إلى الشاشة الرئيسية»**، فيصبح كتطبيق ويعمل بدون إنترنت.
- مصمّمة للإنترنت الضعيف: حجمها صغير جداً (أقل من 100 كيلوبايت تقريباً بدون الأيقونات)، وبلا مكتبات أو خطوط خارجية، وتُحفظ في الكاش من أول فتح.

> لتفعيل النشر أول مرة: من إعدادات المستودع ← **Pages** ← اختر **Source: GitHub Actions**.

### 2) تطبيق Android (APK)
- يُبنى تلقائياً عبر `.github/workflows/android.yml` باستخدام **Capacitor** من نفس الكود.
- **رابط التحميل المباشر (دائم):** https://github.com/abdulrahmanahmedelabed-prog/teacher/releases/latest/download/rehla-alawda.apk
- كل تحديث للكود يبني نسخة جديدة وينشرها تلقائياً في صفحة **Releases**.
- عند التثبيت قد يطلب الموبايل تفعيل «التثبيت من مصادر غير معروفة».

بناء يدوي على جهازك (يتطلب Node 20 و JDK 17 و Android SDK):
```bash
npm install
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```

## 🌍 الموقع
- **صفحة الهبوط:** `landing/index.html` تُنشر في جذر الموقع.
- **التطبيق:** محتوى `www/` يُنشر على المسار `/app/`.
- الرابط: https://abdulrahmanahmedelabed-prog.github.io/teacher/

## 🧪 تشغيل محلي
```bash
cd www && python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`.

## 🗂️ هيكل المشروع
```
landing/
  index.html     صفحة الهبوط (ملف واحد خفيف)
resources/android/  أيقونات تطبيق Android
www/
  index.html     التطبيق
  styles.css     التصميم (فاتح/داكن، من اليمين لليسار)
  data.js        المواد، قوالب التحديات، المراحل، الأوسمة، الاقتباسات
  app.js         منطق التطبيق كاملاً
  sw.js          العمل بدون إنترنت
  manifest.json  إعدادات التثبيت كتطبيق
capacitor.config.json   إعداد تطبيق Android
```

لإضافة تحديات أو مواد أو اقتباسات جديدة يكفي تعديل `www/data.js`.
